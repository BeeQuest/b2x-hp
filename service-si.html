受託システム開発 / SICustom Development

業務を知るエンジニアが、使い続けられるシステムを作る。

B2Xの受託システム開発／SIは、「作って終わり」のSIではありません。自社プロダクトBeeQuestを自分たちで運営している当社は、要件定義から運用までを業務ドメインごと理解し、"現場で本当に使われるシステム"を作ることにこだわります。会計・教育領域の深い知見と、モダンなクラウドネイティブ技術で、SaaS・業務システム・API基盤を開発します。

  • アジャイル・スクラム体制
  • クラウドネイティブ設計
  • 会計・教育ドメインに強い

お問い合わせ

こんな課題、ありませんか？Challenges

"作って終わり"のSIから、"成果を出すSI"へ。B2Xはプロダクト開発会社の視点でシステム開発を進めます。

要件を言語化しきれない

業務フローが複雑で、自社だけでRFPを書けない。要件定義の伴走が欲しい。

01

レガシーで運用負荷が高い

オンプレ・スクラッチ設計が古く、インフラ・アプリ双方のメンテが重荷に。

02

内製エンジニアが足りない

プロダクト開発の経験者採用が進まず、外部パートナーを探している。

03

既存ベンダーと噛み合わない

ドメイン知識が浅いベンダーで、業務要件の齟齬が繰り返し発生している。

04

B2XのSIの強みWhy B2X

自社SaaSを運営し、会計・教育に精通している当社ならではの、統合的な価値提供を行います。

会計・教育ドメイン理解

仕訳・決算・税務・研修運用まで、業務の細部を理解した上で要件定義できるエンジニア・コンサルタントが担当します。会計士・税理士資格者が在籍し、業務要件の翻訳精度が高いのが特長です。

01

クラウドネイティブ設計

AWS／GCPをベースに、Serverless・コンテナ・マネージドDBを活用。ECS / Lambda / Cloud Run、IaC（Terraform / CDK）で、スケーラブルかつ運用負荷の少ない構成を選定します。

02

アジャイル・スクラム

2週間スプリント・レビュー会・レトロスペクティブで、要件変化に強い開発体制。プロダクトオーナー役の伴走も可能です。

03

セキュリティ・品質重視

静的解析・脆弱性診断・自動テストをCI/CDに組み込み、リリース品質を担保。SOC 2／ISMSの要件にも対応します。

04

正社員中心の開発体制

原則すべて社内正社員が担当。コミュニケーションコストを抑え、長期的なプロジェクトにも腰を据えて取り組みます。

05

運用・改善まで伴走

リリース後の監視・SRE・改善提案までセットで提供。"作って終わり"を絶対にしません。

06

提供メニューWhat We Offer

お客さまの課題と段階に応じて、柔軟な関わり方が可能です。

SaaS / Webアプリ開発

BtoB SaaS、顧客向けWebアプリ、社内ポータル等。設計からリリースまで一貫対応。フロント：React / Next.js / TypeScript、API：NestJS / FastAPI / GraphQL、DB：PostgreSQL / MySQL / DynamoDB。

01

業務システム開発

経理・販売管理・受発注・生産管理等、業務フローに合わせた独自システム開発。既存システムとの統合、ワークフロー／承認エンジン、帳票／PDF出力／電子化対応。

02

API基盤構築

社内外システムを繋ぐAPI基盤、マイクロサービス化、イベント駆動アーキテクチャ。OpenAPI仕様設計、API Gateway / Kong / Apollo、メッセージング：Kafka / SQS。

03

モバイルアプリ開発

iOS/Android向けネイティブ・クロスプラットフォーム開発。React Native / Flutter、Swift / Kotlin、Firebase連携。

04

データ基盤・分析

DWH構築、BI接続、学習データ／業務データの統合分析基盤。BigQuery / Snowflake / Redshift、dbt / Airflow、Looker / Metabase。

05

SRE / 運用保守

監視・障害対応・パフォーマンス改善・SLO運用。既存システムの運用継承も可能。Datadog / NewRelic / CloudWatch、インシデント対応フロー設計、SLO / SLA運用。

06
技術スタックReact / Next.js、TypeScript、Node.js / NestJS、Python / FastAPI、Go、AWS、Google Cloud、Firebase、GraphQL、PostgreSQL、Docker / Kubernetes、Terraform / CDK

プロジェクトの進め方Flow

要件定義から運用まで、一貫した体制で支援します。

ディスカバリー

業務課題・ゴール・成功指標を整理。必要ならPoCから着手します。

要件定義・設計

業務フロー・データモデル・UI・非機能要件を確定。

開発・テスト

2週間スプリントで継続的デリバリー。CI/CDで品質を担保。

リリース

受け入れテスト・本番切替・オペレーション移行を支援。

運用・改善

SRE・機能改善・データ分析による継続的改善を提供。

よくあるご質問FAQ

要件定義から依頼できますか？はい、要件定義フェーズ単独でもお受けしております。業務フロー整理・RFP作成支援も可能です。
契約形態はどのようなものがありますか？請負／準委任／ラボ型の3種類を、プロジェクト特性に応じてご提案します。
既存システムの運用保守だけでも依頼できますか？可能です。他社開発のシステムでもまずはアセスメントを行い、段階的に引き受けます。
業種の制限はありますか？特にありませんが、会計・教育・BtoB SaaS領域が得意です。それ以外の領域でも技術軸での支援は可能です。
オフショアは使いますか？原則国内正社員中心の体制です。必要に応じて一部オフショアパートナーを活用しますが、品質管理は当社が一貫して担います。
NDA締結後、概算見積りは可能ですか？もちろん可能です。NDA締結後、1〜2回のヒアリングで概算レンジをご提示します。
