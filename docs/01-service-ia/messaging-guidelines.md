# メッセージングガイドライン

最終更新: 2026-08-03

営業トーク・サイト文言の整合を取るためのルール。実態と乖離する約束はしない。

## 打ち出すべきこと

1. **人材育成の設計** — 入社後「何をどこまでどうできるようになるか」を設計する
2. **実務経験 → 次のステップ → 評価** の一連の流れを BeeQuest 経由で支える
3. **伴走型支援** — 受託も BeeQuest 導入も、構築だけで終わらない
4. **エンジニア在籍 × AI活用** による、現実的なコストとスピードでの受託開発
5. **専門領域もB2Xが直接受ける** — 会計・資金調達・マーケを第3の主軸として前面に出す

## 書いてはいけない／避ける表現

| NG | 代わりに |
|---|---|
| 会計教育コンテンツを単体で提供する | BeeQuest上で会計を学ぶ／BeeQuest経由で提供 |
| API・プラグイン開発を独立サービスとして売る | 受託システム開発の対応領域として記載 |
| 「提携による支援」「提携先と一緒に」を表に出す | B2Xが直接支援する／専門領域支援 |
| 提携先名・個人名を公開ページに列挙する | 体制の裏側は docs 内部メモのみ |
| 未実装機能を「できます」と断言する | 「今後展開予定」「準備中」と明記 |
| 導入事例がないのに実績ストーリーを捏造する | 「準備中」または実在実績のみ |

## トーン

- 誇張より現実的な伴走の説明を優先
- トップは短く、詳細は詳細ページへ
- 「変革」「DX」の多用で中身がぼやけないよう、具体語（オンボーディング、評価、育成設計、freee連携、販管費分析）を使う

## ブランド表記

- サービス名: **BeeQuest**（サイト表記は BeeQuest で統一。口頭の「ビークエスト」も可）
- 会社名: 株式会社B2X
- 第3柱: **専門領域支援**（会計・資金調達・マーケ）
