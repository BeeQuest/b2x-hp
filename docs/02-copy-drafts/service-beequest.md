1. 採用した人材の育成が属人化している
2. オンボーディングが短く、現場に定着しにくい
3. 「何ができれば次のステップか」が不明確で評価が曖昧
4. 研修を実施しても実務に活きない／続かない

## 提供価値

### 育成設計

入社後に「何を、どこまで、どうやってできるようになるか」を設計し、実務経験を積みながら次のステップへ進ませる流れをつくります。

### BeeQuestでの学習

会計を含む教育コンテンツは、単体納品ではなく **BeeQuest上で学ぶ形** で提供します。学習の進捗・定着をプラットフォーム上で把握できます。

### 評価・キャリアへの接続

学習と実務の状況を、評価やキャリアの見通しにつなげる設計を支援します。  
採用投資に見合うかの検証や、評価システムの機能強化は **今後展開予定** です。

### 伴走支援

初期の要件整理・導入設計から、導入後の運用、会社の成長を見据えた長期支援まで伴走します。

## 支援の流れ（例）

1. ヒアリング（現状の育成・評価・業務課題）
2. 育成設計（ゴール定義、カリキュラム／オンボーディング設計）
3. BeeQuest導入・コンテンツ整備
4. 運用伴走（定着支援、改善）
5. 評価・次ステップへの接続（機能は順次拡張）
