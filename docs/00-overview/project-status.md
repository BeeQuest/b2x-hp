## 現状の課題（対応済 / 残）

- 現行サイトは相談内容をAIでつなぎ合わせた初稿であり、詳細レビュー前のまま公開用に見えてしまう
- 記載サービスと、実際に提供できる支援内容が乖離している
- サービス分類（教育プロダクト / システム開発 / 変革支援）と実ページ・実態が不一致
- お問い合わせフォームは UI のみで送信先未設定（GitHub Issue #1）
- ヘッダー・フッター等が各 HTML に複製されている
- 代表者写真がプレースホルダのまま
- 導入事例・ポリシー等の未整備リンク（`href="#"`）が残存

## 方針

| 領域 | 方針 |
|---|---|
| サービスIA | 3柱（BeeQuest育成支援 / 受託システム開発 / 提携による支援） |
| 会計教育 | 単体提供はしない。BeeQuest経由で学ぶ形に統一 |
| API・プラグイン | 独立サービスにせず、受託開発に統合 |
| LMS | 独立ページ廃止。受託開発ページ内の見出し |
| AX・会計DX等 | 自社単独表現をやめ、提携支援として外部リンク |
| 強み | 人材育成・オンボーディング・評価につながる伴走型支援 |
| ドキュメント | まず `docs/` に正本化 → 後で Bequest Internal Docs へ移行 |
| 実装順序 | 文言正本 → Issue化 → 共通パーツ化 → ページ差し替え |
