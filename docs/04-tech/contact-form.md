# お問い合わせフォーム方針

最終更新: 2026-08-03  
関連: GitHub Issue #1

## 現状

- `contact.html`: `action="#"`
- `script.js` `initContactForm()`: クライアント検証後に `alert` のみ。実送信なし
- Render 静的ホスティングのため、サーバーサイド処理は外部サービスが必要

## プロダクト方針（確定）

- **フォームUI・1箇所への集約は現状維持**（新規にフォームを増やさない）
- 狙い: **BeeQuest 関連のお問い合わせを増やす**
- 問い合わせ種別 option は3柱に合わせて更新する（実装フェーズ）

### 種別 option（更新案）

| value | ラベル |
|---|---|
| `beequest` | BeeQuest育成支援について |
| `si` | 受託システム開発について |
| `partners` | 専門領域支援について |
| `recruit` | 採用について |
| `other` | その他 |

（BeeQuestを選択肢の先頭に置き、選びやすくする）

   - B. Formspree / Web3Forms / Static Forms 等

6. **個人情報・プライバシーポリシー**ページとの整合（ポリシーURLが `#` のまま）
